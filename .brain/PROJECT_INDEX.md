# Project Index

## Apps

- `apps/api`: Hono collector/read API.
- `apps/dashboard`: Next.js App Router dashboard.

## Packages

- `packages/analytics-core`: browser SDK and event contracts.
- `packages/analytics-next`: React and Next.js adapters.
- `packages/analytics-server`: trusted server client.
- `packages/auth`: private Better Auth server configuration and operator auth.
- `packages/db`: Drizzle schema and queries.
- `packages/ui`: shared UI primitives.
- `packages/utils`: pure utilities.
