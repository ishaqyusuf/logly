Responsive contract

Not a stacked desktop table

  • Mobile uses a four-item bottom navigation and keeps each target at least 44px.
  • Overview preserves the metric pair, chart, recent event stream, and collection health in that order.
  • Events hide secondary columns at small widths; tapping a row opens the same detail sheet as desktop.
  • Project and settings forms retain visible labels and full-width actions.
  • No horizontal page scroll is allowed at 375px, 768px, 1024px, or 1440px.
